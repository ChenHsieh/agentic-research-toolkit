以下依重要性排序；未修改任何檔案。

1. 【漏譯，圖】原句：`照寫的內容算不出來。代理在這裡停下來並說明。`  
   建議：`無法只根據文字計算。我的案例中，未註明的搜尋設定影響了 13,663 個基因中的 732 個；另有一個過濾步驟完全沒有寫下來。`（英文原文的具體證據被漏掉。）

2. 【術語／技術意義】原句：`讓每個工作階段有自己的一份儲存庫（git worktree）。`  
   建議：`讓每個工作階段各有獨立的工作目錄（Git worktree）。`（worktree 不是另一份 repository／儲存庫。）

3. 【術語一致】原句：`包含寫、送出、檢查叢集上的工作。`  
   建議：`包含撰寫、提交與檢查叢集作業。` Slurm 的 job 建議一律譯為「作業（job）」或「批次作業」，不要和泛指的「工作」混用。

4. 【翻譯腔】原句：`為什麼這些失敗沒有聲音`  
   建議：`為什麼這些失敗不易察覺`；全文的「有聲／無聲的錯」可統一為「顯性錯誤／隱性錯誤」或「會報錯／不會報錯的問題」。

5. 【圖中文字不自然】原句：`錯誤流出去`  
   建議：`缺陷隨成果釋出` 或 `缺陷流入成品`，才能對應 *Defect ships*。

6. 【術語】原句：`程式代理（coding agent）`  
   建議：首次寫作 `寫程式的 AI 代理（coding agent）`，後文簡稱「代理」；「程式代理」容易被理解成由程式實作的 agent。

7. 【術語策略】原句：`任務說明、待辦清單、狀態檔、commit。`  
   建議：`任務說明（brief）、工作清單（task list）、狀態檔（status file；如 STATUS.md）、commit。` brief/status file 可首次中英並列；`commit`、`Git worktree` 建議保留英文。

8. 【圖中文字】原句：`每一步都同意`／`同意計畫`  
   建議：`逐一核准每個步驟`／`核准計畫`；「核准」較符合權限與操作模式的語境。

9. 【翻譯腔】原句：`只能在有邊界的空間裡`  
   建議：`只能在明確設限的環境中`；`不是寫在提示裡拜託它的` 改為 `而非僅在提示詞中要求的限制`。

10. 【術語】原句：`沒有代理坐在那裡一直問佇列。`／`不是讓代理一直去問。`  
    建議：`不需要代理持續輪詢佇列。` 「輪詢」是台灣技術文件較準確的說法；`背景檢查`可寫成「背景監測程序」。

11. 【語意與句法】原句：`一大批其實有分組的東西……之間有很強的相關。`  
    建議：`許多可分群的項目之間呈現很強的相關性，例如基因家族中的基因、個體中的細胞或批次中的樣本。`

12. 【翻譯腔】原句：`單位有分組，就連每一組裡面的結果一起要。`  
    建議：`若分析單位有分組，也要要求提供各組內的結果。`

13. 【技術表述】原句：`對照組和它的條件用不同的量來配對時會報錯。`  
    建議：`若以不同的度量值配對對照組與實驗條件，程式就應報錯。`

14. 【圖中文字】原句：`資料不夠看出效應就說「沒有效應」`  
    建議：`資料不足以偵測效應時，卻宣稱「未見效應」`；科研語氣更精確。

15. 【不自然且誤導】原句：`每個發表的數字對上重做出來的數字。`  
    建議：`逐一比對每個已報告的數值與重建所得的數值。` *reported* 不是「發表」。

16. 【標題／中繼資料意義偏移】原句：`用程式代理做研究`、`每天用 Claude Code 做研究的紀錄`  
    建議：`用 AI 代理做研究`、`一位基因體學博士生在大學叢集上使用 Claude Code 做研究的紀錄`；英文原文沒有「每天」，也不限於 coding agent。

17. 【未譯】原句：`"Every genuine test of a scientific theory..."`  
    建議：補中文：`「任何真正檢驗科學理論的測試，在邏輯上都是試圖反駁或證偽該理論。」` 英文可保留於後。

18. 【翻譯腔】原句：`分岔小徑的花園`、`乾淨結果`、`故意去撈`  
    建議：`分岔路徑的花園`、`看似漂亮的結果`、`刻意挑選有利結果`；較符合台灣統計與研究方法寫作。

19. 【圖說語意】原句：`每個小階段都以一個 commit 過的檔案結束`  
    建議：`每個小階段都產出檔案，並完成一次 commit。` 原句容易被讀成「檔案本身被 commit」。

20. 【用語】原句：`把<a ...>五行的規則檔</a>複製成 CLAUDE.md`  
    建議：`將五行規則檔貼入 CLAUDE.md，再填入括號中的內容。` *copy into* 不是「複製成」。

21. 【語氣】原句：`也會順便稽核它`  
    建議：`也會一併檢核分析`；「稽核」偏正式審計，不像一般研究分析的驗證工作。

22. 【翻譯腔】原句：`這還沒有測到我真正出錯的情境`  
    建議：`這仍不足以說明我真實失敗案例發生的情境`；較準確對應 *This says nothing yet about…*。

23. 【圖中文字】原句：`附引文的摘要。每一句引文都要確認真的存在。`  
    建議：`附原文引述的摘要；每段引述都要逐一核對是否確實出現在論文中。` 「引文」在中文學術語境可能被理解為文獻引用。

24. 【口語直譯】原句：`有一個研究的是「AI 幫忙」感覺起來有多快。`  
    建議：`不過有一項研究比較人們主觀感受到的 AI 協助速度與實際速度。`

25. 【術語與文體】原句：`只有通過與否和錯誤訊息的結尾會回來。`  
    建議：`只將通過／失敗結果及錯誤訊息的末段回傳給強模型。` 需補出回傳對象，`pass/fail` 可依讀者保留英文。
