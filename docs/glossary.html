Glossary

Plain-sentence definitions for the words that come up on this site. One idea each, no jargon inside the definitions.

AI
The broad, familiar umbrella term; this site says "chat assistant" or "agentic tool" instead, because those name what the tool can actually do.
Agentic tool / agent
A tool that can take actions for you (read files, run a check), not just chat back. "Agentic" means able to do things, not only talk.
Interface
The window you type into. The same assistant appears in a website, a desktop app, a terminal (Claude Code), and editor plugins; they differ in what they can touch. See Interfaces.
Prompt
The message you send, instructions plus any text you paste in. A clearer prompt gets a better answer.
Hallucination
When it states a made-up detail with full confidence. The reason you always verify.
Context window
The chat's short-term memory. Paste too much or run too long and the earliest parts fall out of view. See Level 1.
Token
The chunk of text these tools read and are billed in, very roughly a word. Usage limits and API prices are counted in tokens.
Model tier
The size of the model: small (fast, cheap), mid (the everyday default), top (most capable, slower, priciest). The labels change; the tiers do not.
Thinking mode
A setting that makes the model reason longer before answering. It does not touch the internet or your files.
Artifact
A chart, document, or mini-tool the chat builds in a side panel. Good for see-it-and-share-it, not for a reproducible result. See Level 1.
Plan / approve / auto mode
How much an agentic tool may do on its own: plan (reads only), approve-each-step (asks every time), auto (acts, pausing for risky things). See Modes.
Allowlist
A list of commands a tool may run without asking. Should only ever cover harmless read-only commands.
Subagent
A helper agent the main one spins up to run part of a job. Rarely needed for the bench. See Beyond the ramp.
CLAUDE.md
A plain-text house-rules file Claude Code reads each session. The name is a convention; the contents are rules you wrote.
AGENTS.md
The same idea in a shared format other tools (Codex, Cursor, Copilot, Gemini CLI) read. See Level 3.
SKILL.md / skill
A small folder that teaches the assistant one repeated task, loaded only when that task comes up.
Connector / MCP
A plug that lets the assistant reach into another account or database (Drive, Gmail, PubMed, Zotero). MCP is the open standard behind it. See Connect your sources.
Prompt injection
A hidden instruction planted in a document, email, or web page that tries to hijack the assistant into leaking data or taking an unwanted action.
git / GitHub
A tool (git) that keeps a timeline of file changes, and a website (GitHub) that stores those histories online. Built for software teams; usually overkill at the bench.
BAA
A signed Business Associate Agreement, required before real patient data goes to a service. Offered only on Enterprise or qualifying API plans.
Zero data retention
An arrangement where a provider does not store your requests. You have to request and qualify for it; it is not a default.
Dictation (speech-to-text)
Turns spoken words into text, handy at the bench. It mishears too, so verify.
Canonical file
The one real, trusted version everything else should agree with.
Record of truth
You and your raw data. The assistant helps write the record; it does not get to be it.
Decision log
A dated, running record, often a folder of dated files, where you write down significant analysis or methods choices and the reason you made them, so you or someone else can find the reasoning again later.
SOP (Standard Operating Procedure)
A written step-by-step description of how your lab performs a routine task the same way every time, like accessioning a sample or running an instrument.
Accessioning
The process of logging a new sample into your lab's tracking system with an ID, source, and date when it first arrives.
Specific aims
The short opening section of an NIH-style grant or fellowship application that states, in a few sentences each, the specific goals the proposed work will accomplish.
Rotation student
A graduate student who works in a lab for a short trial period, often one term, before deciding whether to join it for their thesis.
