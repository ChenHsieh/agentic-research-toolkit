Tools tried

In October 2026 I set up the open-source research agents from the Reading list on our university cluster and gave each one task from my own work, then checked every output by hand. This page is the picture version. It is a small feasibility diary, not a ranking: each tool got one task that suited it, once, on one cheap model. A failure can belong to the tool, the model, the gateway or my task.

Read the last column. In these seven small trials, the errors I found were mostly in the sentence after a correct-looking output. That is a reason to check both the table and the claim. It is not a measurement of what agents are good at: one task is not a rate, and I chose tasks I could check.

What each row did not test. PaperQA2: only its manual local-papers path, not its literature-search agent. Biomni: without its data lake, so as a code-writing database assistant, not its curated tools. Virtual Lab: the meeting, not the design-and-validation workflow in its paper. Paper2Agent: its checks confirm it reproduces my tables, not that a new question is answered correctly. CellVoyager: a setup failure through one gateway key, not a verdict on its analyses.

Why one tool never ran

Notes for each tool

Codex CLI read-only review of a figure helper I use
Found four edge cases nobody had tested, such as values below 1e-10 printed as "0". One of its concrete claims was wrong when I ran the input: it said a value printed as "1e+09"; it printed "1000M". Notes
Aider write tests from a plan, $0.0016
Wrote working tests in one call. I then broke the code four ways on purpose and the tests caught all four. On the way, Python reused a stale compiled copy of the file and made a correct file look broken, a quiet failure of its own. Notes
Paper2Agent my two manuscripts as tools Claude Code can query
Its own checks still pass (61 of 61). It answers "how many genes, from which file, at which commit", and warns when an old number is still in circulation. Setup takes an afternoon per paper.
PaperQA2 a question over 20 open-access papers on young genes
Answered in three paragraphs with a citation on every sentence. Checking the citations found one overreach: "at most a third come from divergence" became "the majority are de novo", which the paper does not say. Its agent mode crashed on a version mismatch; the plain mode works. Notes
Biomni look up and compare five tandem-duplicated Arabidopsis genes
Wrote and ran its own database code; the table matched UniProt. Then it concluded one gene had "functionally diversified" because it had more GO terms, which mostly means it was studied more. Its install left out three packages. Notes
Virtual Lab four role-played experts plan how to show young genes are real, $0.01
A sensible ranked plan in six minutes, close to what my chapter actually did. It also listed the two parent species of my hybrid as outgroups, which they are not, and used stock thresholds with no reason given. This tested the meeting only. Notes
CellVoyager reanalyse a public single-cell dataset
Did not run. Five attempts failed before any analysis: a stale package picked up from my home directory, then two parts of its code that need the same model named two different ways when everything goes through one gateway key. It expects OpenAI and Anthropic keys of its own. Notes
