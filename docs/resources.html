Resources: where to grow next

Once you are comfortable, these are good places to find ready-made skills: named, reusable procedures other people have written for research tasks. A skill is just a folder with a SKILL.md file you can read like a recipe before you run it. Treat these lists like a protocol from another lab: useful, but read it and check it against your own data first. Links checked Aug 2026.

Curated skill libraries

⭐anthropics/skillsAnthropic's official Agent Skills, the cleanest examples of the format and the source several skills in this toolkit were adapted from. 🔬InternScience/Awesome-Scientific-SkillsA large curated set for science (bioinformatics, chemistry, statistics, writing). Tool-agnostic: Claude Code, Cursor, Codex, Gemini CLI. 📚travisvn/awesome-claude-skillsA broader awesome-list of skills, tools, and resources, including scientific collections.

Scientific writing

✍️labarba/sciwriteEditorial review in five passes (clutter, weak verbs, sentence flow, keyword consistency, number/citation integrity), based on Stanford's Writing in the Sciences method. It gives feedback rather than rewriting, and does not touch your data or claims. A strong fit for the "drafts, you verify" habit.
⚠️

These are community and vendor lists that change often, and quality varies skill to skill. Read the SKILL.md before you rely on one, keep unpublished data out, and spot-check any generated citations against the source.
