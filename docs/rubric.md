# Rubric: is this worth the setup?

A one-page decision aid. The honest default is: **start with plain chat, and only add tooling
when the task clearly outgrows it.** Setup has a cost; make the work earn it.

## Chat vs. agentic, at a glance

| Situation | Use plain chat (Level 1) | Use an agentic tool (Level 2/3) |
|---|---|---|
| One day's bench notes | Yes | Overkill |
| Drafting one paragraph or one entry | Yes | Overkill |
| A note or table that fits in the chat box | Yes | Usually overkill |
| A spreadsheet with thousands of rows | No, too big to paste well | Yes |
| Cross-referencing many files | Painful by hand | Yes |
| "Find every sample where X" across a dataset | No | Yes |
| Keeping a long-running project internally consistent | No | Yes (Level 3) |
| You are still figuring out what you want | Yes, explore here first | Not yet |

## Wet-lab vs. dry-lab

The split is less about your job title and more about what the task is right now.

- **Recording at the bench** (what you just observed, today's experiment): this is
  Level 1 work. There is nothing to search yet, just an observation to write down cleanly.
  Plain chat is the right tool and adding file access buys you nothing.
- **Curating and analyzing** (folding many results into a shared table, checking a big
  dataset for consistency, cross-referencing files): this is where an agentic tool starts to
  pay off. The data has grown past what you can hold in your head or paste into a box.

Most people do both at different times. Match the tool to the task in front of you, not to
your role in general.

## The "is it worth the setup?" test

Ask these in order. Stop at the first "no."

1. **Is the data too big or too scattered to just paste into a chat?**
   If no: use plain chat. You are done.
2. **Will I do this same task repeatedly, or across many files?**
   If no: use plain chat. A one-off is not worth a setup.
3. **Do I need the answer to come from actual files, checked for consistency?**
   If no: plain chat is probably fine.
4. **Will this project run long enough that "stay consistent over time" is a real problem?**
   If yes: this is Level 3 territory (house rules, a brief, a decision log). If no, an
   agentic tool without the full Level 3 scaffolding is fine.

If you answered "yes" down to question 3, an agentic tool (Level 2) earns its keep. If you
also said yes to 4, add the Level 3 templates.

## The rule that does not change with the level

Whatever level you are at:

> **The assistant drafts and proposes. You are the record of truth, and nothing canonical changes
> without you approving it.**

At Level 1 that is automatic, because the assistant cannot touch your files. At Levels 2 and 3 you
keep it true by leaving approval on and asking the assistant to quote its sources back to you.
