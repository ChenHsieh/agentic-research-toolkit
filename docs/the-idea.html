The idea

An agent is a medium, like a pipette, R, or a cluster. It makes doing things cheap. It does not decide what is worth doing, or whether the answer is right. That part is still you.

What you bring, what it brings

flowchart TB
  Y["You
imagination · experience"] -->|a question| A["Agent
code, jobs, reading"]
  A -->|results| J["You
instinct · taste"]
  J -->|the next question| Y
  • Imagination asks the question. "What if young genes behave differently?" The agent never asks that on its own.
  • Experience knows the traps: batch effects, the wrong unit, the control that never ran. You write it into the rules file so the agent stops repeating them.
  • Instinct notices when a result is too clean, too fast, or too convenient. This is the most important skill, and the agent doesn't have it.
  • Taste decides which of ten possible next steps is worth a week, and when a figure or a paragraph is good enough.

What changes

Doing the work used to be the slow part. Now it isn't, so the loop turns much faster.

flowchart TB
  Q[Question] --> T[Try it] --> L[Look]
  L --> J{Judge}
  J -- surprising --> B[Try to break it] --> L
  J -- holds up --> K[Keep it]
  J -- boring --> Q

The agent speeds up "Try it" and "Try to break it". "Look" and "Judge" stay yours. A faster loop means you need more judgement, because you're making more calls per day, and some of the results will be confidently wrong.

Where the value moves

flowchart TB
  B["Before
idea → weeks of coding → judgement"]
  N["Now
idea → hours of agent work → judgement"]
  B --> N

When doing things is cheap, the scarce parts are the ideas and the judgement. That's the good news. The parts of research people actually train for are worth more now, not less.

So, to get better at this

  • Read papers and other people's code. Imagination needs material.
  • Do some analyses by hand. Experience comes from having seen it break.
  • Look at raw data and every figure yourself. That's how instinct gets trained.
  • Show work to people whose judgement you trust. That's how taste gets calibrated.
  • Then let the agent do the typing.
