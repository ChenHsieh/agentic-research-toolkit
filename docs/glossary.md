# Glossary

Plain-sentence definitions for the words that come up in this guide. One sentence each, no
jargon inside the definitions.

**Chat assistant (chatbot)**
A program you type messages to and get written answers from, like texting with a very
well-read but sometimes-wrong assistant; Claude and ChatGPT are examples.

**Prompt**
The message you send the assistant, including any instructions and any text you paste in; a clearer
prompt gets you a better answer.

**AI (artificial intelligence)**
The broad, familiar umbrella term for these tools; this guide mostly avoids it and says
"chat assistant" or "agentic tool" instead, because those name what the tool can actually do.

**Agent / agentic tool**
A tool that can take actions for you, such as reading and searching your files or running
a check, instead of only chatting; "agentic" just means "able to do things, not only talk."

**Hallucination**
When the assistant states something that sounds confident and correct but is actually made up, such
as inventing a number or detail that was never in your notes; this is the main reason you
always verify its output.

**Context window**
The amount of text the assistant can pay attention to at once, like its short-term memory for the
current conversation; paste in too much and older parts fall out of view.

**Token**
The small chunk of text the assistant reads and counts in, roughly a few characters or part of a
word; "context window" and usage limits are measured in tokens.

**Canonical file**
The one real, trusted version of a file that everything else should agree with, as opposed to
old copies, drafts, or scratch versions; naming your canonical files is a Level 3 habit.

**Verify / verification**
Checking the assistant's output against what actually happened or what the source file actually says,
before you rely on it; the human always does this.

**Record of truth**
The authoritative account of what really happened, which is you and your raw data, not the
assistant's draft; the assistant helps you write the record, it does not get to be the record.

**Cloud sync (OneDrive, Dropbox, Google Drive)**
A service that keeps a folder copied between your computer and the cloud; useful, but it can
change files' "date modified" times, which is why this guide says to sort logs by the date in
their filename instead. See [Level 3](level-3-starter-kit.md).

**`CLAUDE.md`**
A plain text file of house rules kept in a project folder that an assistant reads and
follows each session; the name is a convention, the contents are just rules you wrote.

**Decision log**
A short dated file recording what you did and decided, so the reasoning behind a project can
be reconstructed later; see the [template](templates/decision-log-template.md).

**SOP (standard operating procedure)**
A written step-by-step description of how your lab performs a routine task the same way every
time, such as accessioning a sample or running an instrument; an SOP is essentially the same
shape as an agent instruction file, written for people.

**Accessioning**
The process of logging a new sample into your lab's tracking system with an ID, source, and
date when it first arrives.

**Specific aims**
The short opening section of an NIH-style grant or fellowship application that states, in a
few sentences each, the specific goals the proposed work will accomplish.

**Rotation student**
A graduate student who works in a lab for a short trial period, often one term, before
deciding whether to join it for their thesis.
