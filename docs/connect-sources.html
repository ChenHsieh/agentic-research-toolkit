Connect your sources learn when needed

A connector (built on an open standard called MCP) is a plug that lets the assistant reach into another account or database, like Drive, Gmail, Calendar, PubMed, or Zotero, so it can search and read that content while it helps you, instead of you copy-pasting the same material every session.

When to use which

Reach for…WhenSimpler alternative
Drive / Gmail / CalendarIt needs to look across many files or messagesAttach the one file
PubMedFetch or summarize by ID or queryA plain browser search for a single paper
ZoteroYour library already lives therePaste the one citation
Plain file access (Level 2)The material is already downloadedKeeps data local, setup simpler

Two real risks, stated plainly

📤

1. Whatever a connector reads leaves your machine for the provider's servers. It is not a private channel. Keep unpublished, patient, or embargoed data out of connected accounts.

🎣

2. Prompt injection. A booby-trapped instruction hidden inside an email, a document, or a web page can try to make the assistant leak your data or take an action you did not ask for. The more it can read and do, the more this matters.

How to stay safe

  • Read the permission screen and grant the least it needs.
  • Connect trusted sources only, one at a time.
  • Keep sensitive libraries and accounts out entirely.
  • Vet any community-built connector before installing it.
  • A connector scoped too broadly by the first person who sets it up tends to get copied lab-wide by example, so check exactly which folders or inboxes yours reaches before telling anyone else to set theirs up the same way.
  • You do not need connectors to get value from this site. They are a Level 3 convenience, not a requirement.
