Interfaces: where you type

The interfaces differ in how much of your computer they can touch, not in how smart they are. A non-coder does about 90 percent of useful work in the website or desktop app.

The route for a bench scientist: the website, then the desktop app with connectors, then Claude Code only once a helper has set it up. The swipe test picks your level; this table picks the window once you are there.

A little more on each

  • Website / desktop app. Nothing installed. It cannot touch your files unless you attach them, which is a feature. The desktop app adds connectors so it can read across Gmail, Drive, or Calendar in plain language.
  • Claude Code. A terminal window where an agent works across a folder. This is where modes and instruction files matter.
  • Editor extensions and Cursor. The same agent, shown next to your files with a clearer view of proposed changes. Best if you or a helper already live in that editor.
  • Codex. Good for handing off a self-contained task and reviewing a finished result rather than watching each step.
📄

All of these can read a house-rules file to stay inside your guardrails, so the setup you write once travels between windows.
