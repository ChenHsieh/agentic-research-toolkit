# Resources: where to grow next

Once you are comfortable with the ramp, these are good places to find ready-made **skills**:
named, reusable procedures other people have written for research tasks, that you can drop
into an agentic tool. You do not need any of these to follow this guide. They are for when
you want to go further.

A skill is just a folder with a `SKILL.md` file of instructions. You can read one like a
recipe before you ever run it, which is the honest way to decide whether you trust it. Treat
these lists the way you would treat a protocol from another lab: useful, but read it and
check it against your own data before you rely on the output.

## Curated skill libraries

- **[anthropics/skills](https://github.com/anthropics/skills)** — Anthropic's official public
  collection of Agent Skills. The best place to see how a well-made skill is structured, and
  the source several skills in this toolkit were adapted from.
- **[InternScience/Awesome-Scientific-Skills](https://github.com/InternScience/Awesome-Scientific-Skills)**
  — a large curated set of agent skills specifically for scientific research (bioinformatics,
  cheminformatics, structural biology, clinical research, statistics, literature search,
  scientific writing). Tool-agnostic: works with Claude Code, Cursor, Codex, and Gemini CLI.
- **[travisvn/awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills)** — a
  broader "awesome list" of skills, tools, and resources, including scientific collections.
  Good for browsing beyond research tasks.

Links checked August 2026. These are community and vendor lists that change often; a skill
that looks abandoned or contradicts your data is not worth forcing.

## The rule that still applies to all of it

Nothing on this page changes the core habit:

> **The assistant drafts and proposes. You are the record of truth, and you verify before you
> rely on anything.**

A fancier skill or a bigger library does not remove the need to check the output. It just
gives the assistant a better starting point.
