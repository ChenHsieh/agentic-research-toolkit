Practice

Seven cases. Each happened in my work, lightly simplified. For each, decide whether the result is done (PASS), wrong (FAIL), or cannot be judged yet (BLOCKED). Then see what happened.

1. A comparison against a control came back. The agent's summary: "No significant difference from control. Check passed." The control table has 0 rows.

Nothing compared with nothing is not a difference. The control never ran. This one happened to me; now an empty control fails loudly.

2. A cluster job exited with code 0. The output file exists. It has a header and no data rows.

Exit code 0 means the program stopped without an error, not that it produced anything. A step is done when the output is checked.

3. Across 48 attention heads in 6 layers, a score correlates with an effect: rho = +0.45, p = 0.001. Computed within each layer, the same correlation is rho = -0.11, p = 0.47.

The heads are grouped. The pooled correlation came from differences between layers, not between heads. The claim about heads does not hold.

4. Rebuilding a chapter from its Methods text, the agent's count matches the paper exactly. Its log notes that the Methods did not state a software setting, so it picked the one that matched.

A guess that matches hides the gap. The Methods are incomplete. In my case, the default setting changed 732 of 13,663 genes.

5. A website build passes every check: inputs pinned, checksums match. The source repository's corrections log changed yesterday.

Pinned inputs prove the site matches what it was built from, not that the source still stands. My site served a withdrawn gene set for four days with every check green.

6. An intervention shows no effect. In that arm, 2% of the positions that could change actually changed.

An arm that barely moved cannot show an effect. The null is a fact about the sampler, not about the system.

7. Two classification methods are run on the same reads. They agree on 99.5% or more of reads at family level. Most genus-level disagreement is between two genera in the same family. The report says: family-level results are robust; a few named genera depend on the method.

The claim matches the evidence and states its limit. The disagreements are reported, not averaged away.

Most of these are BLOCKED. That matches my experience: the common failure is not a wrong number, it is a number that was never really measured.
