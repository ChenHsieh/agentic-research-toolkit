The ramp

Level 1 · Chat only start here

The assistant sees only what you paste or attach. Nothing on your computer is touched. This needs a free chat account and copy-paste, and for most people it is the only level they ever need.

1.1 · The notebook-entry prompt

Copy this, paste it into Claude or ChatGPT, and add one real bench note where it says so. The magic is point 3: it makes gaps stay gaps instead of getting invented.

notebook-entry-prompt.txt 
You are helping me turn a rough bench note into a clean lab-notebook entry.

Do three things:
1. Rewrite my shorthand into clear, full sentences, using a consistent structured
   format with these fields: Date, Experiment, Plant material / sample, Treatment,
   Measurement, Result, Notes. Mark a field "[not recorded]" if my note lacks it.
2. List separately, under "Missing or unclear," any field a reader would need but
   cannot find, and any place my note is ambiguous.
3. Do not invent, guess, or fill in any value I did not write. If a number, unit,
   date, or ID is missing, say it is missing. Do not assume standard values.

Keep my original meaning. Do not add interpretation I did not state.

Here is my bench note:
---
[PASTE YOUR NOTE HERE]
---

You get back a clean, fielded entry plus a "Missing or unclear" list that names what you forgot to write down. Then you read every field against what you actually did, fix anything wrong, and retype the final version into your real notebook. That step is the point. See the verification checklist.

1.2 · Keeping a chat sharp (the context window)

A chat has a limited short-term memory, called the context window. When it fills up, the assistant starts to forget.

  • Open a fresh chat per task rather than running one endless thread.
  • Start it with a short "context pack" (the goal, a few key facts, any correction you already made) instead of re-pasting whole documents.
  • Signs the window is full: it forgets an instruction you gave, repeats itself, or gets vaguer.

At Level 2 and up, Claude Code adds /clear and /compact. Compaction throws away detail to save room, so verify anything important afterward. When facts must survive a reset entirely, move them into a Level 3 file.

1.3 · Artifacts (a chart or mini-tool beside the chat)

The chat can build a quick chart, a small calculator, or a one-page handout in a side panel, with no coding.

  • Artifact = see-it-and-share-it: a throwaway chart, a dilution or molarity calculator, a shareable one-pager.
  • A notebook, or a Level 2/3 script = prove-it-and-keep-it: anything reproducible, reviewed, or headed for a paper.
🚫

An Artifact has no saved, rerunnable code behind it and can get arithmetic wrong without warning, so check every number. Never share an Artifact link built from unpublished data — a shared link can expose that data to anyone who opens it.

1.4 · Which model, and when to turn on "thinking"

Every assistant comes in a few sizes. The marketing labels churn, but the tiers are stable, so read the picker rather than a name you remember.

TierUse forThinking
Mid (the everyday default)Most drafting, summarizing, and question-answeringOff
Top (most capable, slower, priciest)Reasoning-heavy or high-stakes work: checking a calculation, testing a manuscript's logic, planning a multi-step analysisOn
Small (fastest, cheapest)Many repeated simple jobs (not a beginner concern)Off
⚠️

A smarter model is not a more truthful one; the top tier can still be confidently wrong, so verify regardless. Thinking mode only makes the model reason longer. It does not give it access to the internet or your files. File access is a separate step (Level 2).

When Level 1 is all you need

If your job is "make today's messy notes readable and consistent," you are done. Move to Level 2 only when you find yourself pasting the same background over and over, or wishing the assistant could look across many files or a big spreadsheet.
